# MathVerse — Phase 1

เว็บแอปต้นแบบสำหรับแพลตฟอร์มเรียนคณิตศาสตร์ อนุบาล 1 ถึง ม.6

## สิ่งที่ทำได้ในเฟส 1
- หน้าเริ่มต้นโดยไม่ต้องสมัครสมาชิก
- กรอกชื่อเล่นและวันเกิด
- คำนวณอายุจากวันเกิด
- แนะนำระดับเริ่มต้นตามอายุ (เป็นเพียงคำแนะนำ)
- เปิดดูระดับชั้นทั้ง 15 ระดับ และเลือกเรียนล่วงหน้าได้
- Dashboard พร้อมเมนูหลัก 6 หมวด
- แสดงมาสคอตน้องพาย น้องมิว และพี่ซิกมาร์ในรูปแบบ UI ต้นแบบ
- บันทึกโปรไฟล์ไว้ใน localStorage ของอุปกรณ์
- PWA manifest และ service worker พื้นฐาน

## ต้องติดตั้ง
- Node.js 18 หรือใหม่กว่า
- npm

## เริ่มใช้งาน
```bash
npm install
npm run dev
```
เปิด URL ที่ Vite แสดงใน terminal

## สร้างไฟล์ production
```bash
npm run build
npm run preview
```
ไฟล์เว็บที่ build แล้วจะอยู่ใน `dist/`

## โครงสร้าง

mathverse/

## หมายเหตุสำคัญ
- นี่คือ Phase 1 starter ที่รันได้ ไม่ใช่ระบบ production ที่ผ่านการทดสอบทุกอุปกรณ์แล้ว
- ข้อมูลโปรไฟล์เก็บใน browser เครื่องนี้เท่านั้น การล้างข้อมูล browser อาจทำให้ข้อมูลหาย
- เนื่องจากไม่มีระบบสมัครสมาชิกหรือ backend จึงยังซิงก์ข้อมูลข้ามอุปกรณ์ไม่ได้
- วันเกิดเป็นข้อมูลส่วนบุคคลของเด็ก ควรเพิ่มความยินยอมจากผู้ปกครอง นโยบายความเป็นส่วนตัว และมาตรการคุ้มครองข้อมูลก่อนเปิดให้ใช้งานจริง
- ระดับชั้นที่แนะนำจากอายุเป็นเพียงค่าเริ่มต้น ไม่ใช่การประเมินความรู้
- เนื้อหาหลักสูตรและข้อสอบทางการต้องผ่านการตรวจสอบกับเอกสารกระทรวงศึกษาธิการ/หน่วยงานเจ้าของเนื้อหาและสิทธิการใช้งานก่อนเผยแพร่
- แอปมือถือในเฟสนี้ใช้แนวทาง PWA: สามารถเพิ่มไปยังหน้าจอหลักจากเบราว์เซอร์ที่รองรับได้ ยังไม่ใช่ native Android/iOS app
